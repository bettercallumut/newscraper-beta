# The Sentinel Protocol

**The Sentinel** is an autonomous intelligence system designed to monitor a user-defined grid of sources, analyze incoming intel in real-time, and alert a human operator about newsworthy events. Upon approval, it autonomously generates a visual asset and broadcasts the intelligence to a designated Instagram account.

## Core Components

1.  **The Collectors (Scrapers):** Agents that pull raw data from Telegram, RSS feeds, APIs, and X.
2.  **The Analyst (AI Core):** The brain that processes raw data, assigning it a "News Value Score".
3.  **The Sentinel (Alerting System):** The trigger that checks the score against a threshold and pushes high-value intel to the Command Center.
4.  **The Command Center (Web UI):** A FastAPI & React dashboard for operators.
5.  **The Broadcaster (Instagram Poster):** The operative that takes an approved alert and publishes it.

## Getting Started

1.  **Install dependencies:**
    ```bash
    poetry install
    ```
2.  **Configure your environment:**
    *   Copy `.env.example` to `.env`.
    *   Fill in the required API keys and settings.
3.  **Run the database migrations (if applicable).**
4.  **Start the services:**
    *   Run the FastAPI server.
    *   Run the Celery worker and beat scheduler.
